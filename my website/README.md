## 📁 Cấu trúc thư mục
- `index.html`: Trang chủ giới thiệu tổng quan.
- `about.html`: Trang giới thiệu văn hóa ẩm thực 3 miền.
- `products.html`: Trang thực đơn món ăn nổi bật.
- `contact.html`: Trang liên hệ phản hồi.
- `css/style.css`: File thiết kế giao diện chung.
- `images/`: Thư mục chứa hình ảnh minh họa (`banner-am-thuc.jpg`, `pho.jpg`, `banh-mi.jpg`, `bun-cha.jpg`).
